# Sistem Berita Acara — Product Context

## Product
Internal document workflow system for Pertamina Patra Niaga SSC ICT.
Digitizes the Berita Acara (handover/serah-terima) process: creation, PJ signature, manager approval, and archiving.

## Register
product — design serves the workflow, not the brand.

## Users
- **Admin Gudang & Barang** — creates BA, fills details, uploads photos, submits for PJ signature
- **Penanggung Jawab (PJ)** — reviews the submitted BA, signs digitally via magic link
- **Reviewer / Manager** — reviews signed BA, approves or rejects with reason
- **Admin IT** — manages user accounts and master data

## Context
Desktop-first internal tool. Users are Pertamina employees, not tech consumers. The interface must feel like enterprise-grade internal software — familiar, clear, and trustworthy — not like a SaaS product or public-facing app.

## Tone
- Language: formal Indonesian for labels and actions; English for technical terms (Dashboard, Draft, Archive, Status)
- Copy voice: professional, precise, like an internal IT system — not marketing, not conversational AI
- Use "Anda" not "kamu"
- Avoid jargon, avoid exclamation points, avoid empty filler phrases

## Brand
- Pertamina Patra Niaga corporate identity
- Primary: #1D4ED8 (blue — system action color)
- Danger/accent: #DC2626 (red — Pertamina brand + warnings)
- Keep existing color palette; refine application

## References
- Atlassian Jira for structured workflow UI
- Linear for clean typographic clarity
- SAP/enterprise ERP for data density and reliability feel

## Anti-patterns
- No SaaS-cream warm backgrounds
- No gradient text
- No glassmorphism decoration
- No eyebrow/kicker text on every section
- No AI-generated copy patterns ("Dengan mudah", "Selamat datang di", etc.)
